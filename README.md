منصة تعلم تفاعلية عربية تعمل من المتصفح دون الحاجة إلى خادم أو اتصال إنترنت. تشمل **10 محاضرات و6 ورش تطبيقية**، مع شرح متدرج وأمثلة وبطاقات مراجعة واختبارات وتطبيقات حسابية. وهي مبنية على المواد التي قدمها صاحب المشروع، ولا تستنسخ نص الكتاب المرجعي كاملًا.

## التشغيل

1. حمّل المستودع كاملًا من **Code → Download ZIP** أو عبر `git clone`.
2. افتح ملف `index.html` في متصفح حديث (Chrome أو Edge أو Firefox).
3. استخدم رابط **«عن الأستاذ والمرجع»** لفتح الصفحة المستقلة `about.html`.
4. يمكن حفظ التقدم في المتصفح؛ واستخدام **تصدير التقدم** و**استعادة التقدم** للنسخ الاحتياطي.

> **مهم:** يجب الاحتفاظ بمجلد `assets/` بجوار ملف `index.html`؛ لأن CSS وJavaScript وصورة الغلاف موجودة فيه. لا تحتاج إلى `npm` أو استضافة محلية.

## المحتوى

- المحاضرات 1–6: أسس البحث، خطواته، المتغيرات والفرضيات وتصميم البحث والمقاييس والصدق والثبات.
- المحاضرات 7–10: جمع البيانات والاستبيانات، المجتمع والعينات، تجهيز وتحليل البيانات، واختبار الفرضيات.
- الورش: كتابة التقرير، صياغة العنوان والأسئلة والأهداف، المتغير الوسيط والمعدّل، الدراسات السابقة والفجوات، الإطار النظري، وصياغة المشكلة.
- الاختبارات الموضوعية تُصحّح تلقائيًا؛ الأسئلة المقالية تعرض نماذج للإجابة وتُراجع ذاتيًا.

## التنقل على الهاتف

- يوجد شريط ثابت أسفل صفحة التعلم يحتوي على **↶ رجوع** و**⌂ الرئيسية**.
- **رجوع:** يعود إلى آخر شاشة سابقة داخل المنصة (المحاضرة، الوحدة، البطاقات، الاختبار، أو السؤال). إذا بدأت من رابط مباشر ولم تكن هناك شاشة سابقة محفوظة في جلسة التصفح، يعيدك إلى الرئيسية.
- **الرئيسية:** ينتقل فورًا إلى لوحة الدروس، دون مسح الإجابات أو إنجاز الطالب.
- الشريط متاح أيضًا في صفحة **عن الأستاذ والمرجع**؛ الرجوع يستخدم سجل المتصفح إذا كانت الصفحة السابقة من الموقع نفسه.
- سجل تنقل الشاشات مؤقت خلال جلسة الصفحة، بينما بيانات التقدم محفوظة بمفتاح `research_course_v3` كالسابق.

## تشخيص فتح المنصة على الهاتف

- افتح **[صفحة اختبار الاتصال الخفيفة](https://mohammednageebmubarak.github.io/research-methodology-interactive/connection-test.html)**. لا تحتاج إلى CSS أو JavaScript خارجي.
- إذا ظهرت رسالة نجاح الاختبار لكن لم تظهر الدروس في [المنصة](https://mohammednageebmubarak.github.io/research-methodology-interactive/)، فالمشكلة غالبًا تتعلق بتنزيل أو تنفيذ ملفَي JavaScript أو بذاكرة/إعدادات المتصفح. تظهر الآن رسالة تشخيص داخل المنصة بدل الصفحة الفارغة.
- إذا لم تفتح صفحة الاختبار أيضًا، اختبر نفس الرابط باستخدام Wi-Fi ثم بيانات الهاتف، وافتحه من Chrome أو Safari مباشرة، وجرب نافذة خاصة أو تعطيل VPN مؤقتًا.
- حافظنا على مفتاح تخزين تقدم الطلاب والأسئلة كما هو. لا تحذف بيانات الموقع أو ذاكرة التخزين المحلية دون تصدير تقدمك أولًا.
